# 🧠 Deep Learning: 30 вопросов с разбором

Вопросы по нейросетям, backprop, оптимизаторам, CNN, RNN и attention. Уровень: middle ML / DL engineer.

---

## 1. Как работает обратное распространение ошибки?

**Короткий:** backprop = применение цепного правила. Считаем ∂L/∂w для каждого веса через цепочку производных от loss к w.

**Шаги:**
1. Forward pass: считаем выход и loss.
2. Backward pass: с конца сети, для каждого слоя: ∂L/∂w = ∂L/∂y · ∂y/∂w, передаём ∂L/∂x_prev дальше назад.
3. Update: w -= lr · ∂L/∂w.

**Подвох:** на собесе просят написать backprop для линейного слоя y = Wx + b с MSE loss. Ответ:
- ∂L/∂y = 2(y - target)/N
- ∂L/∂W = ∂L/∂y · x^T
- ∂L/∂b = ∂L/∂y
- ∂L/∂x = W^T · ∂L/∂y

## 2. Зачем нужны функции активации?

**Короткий:** без них сеть = одна большая линейная регрессия, как бы много слоёв ни добавляли. Нелинейность позволяет аппроксимировать произвольные функции.

**Сравнение:**

| Активация | Формула | Плюсы | Минусы |
|-----------|---------|-------|--------|
| Sigmoid | 1/(1+e^-x) | Гладкая, (0,1) | Vanishing gradients, не центрирована вокруг 0 |
| Tanh | tanh(x) | Центрирована | Vanishing gradients |
| ReLU | max(0,x) | Быстрая, нет vanishing | «Умирает» при x<0 |
| Leaky ReLU | max(αx,x) | Не умирает | Лишний гиперпараметр |
| GELU | x·Φ(x) | Гладкая, работает в трансформерах | Чуть медленнее ReLU |
| Swish/SiLU | x·sigmoid(x) | Гладкая | Чуть медленнее ReLU |

**Где что:** скрытые слои CNN/MLP → ReLU. Скрытые слои трансформеров → GELU/SwiGLU. Выход бинарной классификации → sigmoid. Выход многоклассовой → softmax.

## 3. Что такое vanishing/exploding gradients и как лечат?

**Vanishing:** градиенты уменьшаются (умножаются на <1 много раз) при backprop → нижние слои почти не учатся. Классическая проблема глубоких MLP и RNN с sigmoid/tanh.

**Exploding:** градиенты растут экспоненциально → веса улетают, NaN.

**Лекарства:**
- **ReLU/GELU** вместо sigmoid/tanh.
- **Хорошая инициализация:** Xavier для tanh, He для ReLU.
- **Batch/Layer Norm:** стабилизируют распределение активаций.
- **Residual connections:** градиент течёт «в обход».
- **Gradient clipping:** обрезка по норме (стандарт для RNN).
- **LSTM/GRU** вместо vanilla RNN.

## 4. Что делает Batch Normalization и почему она работает?

**Короткий:** нормализует активации по батчу к среднему 0, std 1, потом обучаемое γ·x + β.

**Зачем:**
- Стабилизирует распределение активаций → можно использовать большие learning rate.
- Лёгкая регуляризация (шум от батча).
- Снижает зависимость от инициализации.

**Подвохи:**
- Зависит от размера батча: на batch=1 ломается. Используйте GroupNorm.
- Train vs Eval: на train считает по батчу, на eval использует running mean/var. Забыли model.eval() → метрики плывут.
- В трансформерах используется **Layer Norm**, а не Batch: batch norm плохо работает с переменной длиной последовательности.

**Альтернативы:** Layer Norm (по features в одном примере), Group Norm (по группам каналов), Instance Norm (для генерации).

## 5. Чем отличаются SGD, Momentum, Adam, AdamW?

| Оптимизатор | Формула обновления | Когда брать |
|-------------|-------------------|-------------|
| **SGD** | w -= lr · g | Простой, хорошо обобщает, нужно тюнить LR |
| **SGD + Momentum** | v = β·v + g; w -= lr·v | Ускоряет, гасит осцилляции |
| **Adam** | Адаптивный LR на параметр + momentum | Быстрая сходимость, хорош «из коробки» |
| **AdamW** | Adam с корректным L2 (decoupled weight decay) | Стандарт для трансформеров и DL |

**Что говорить на собесе:** Adam — быстрая сходимость, но иногда хуже обобщает чем SGD. SGD + momentum — золотой стандарт для CV (если есть время на тюнинг). AdamW — дефолт для трансформеров.

**Подвох:** в оригинальном Adam weight_decay реализован неправильно (зависит от lr через адаптивный momentum). AdamW исправляет.

## 6. Что такое learning rate scheduler?

**Зачем:** константный LR — компромисс. Большой → не сходится в конце, маленький → учится вечно.

**Популярные:**
- **Step decay:** lr делится на γ каждые N эпох. Простой.
- **Cosine annealing:** lr плавно падает по косинусу до min_lr. Стандарт.
- **Cosine with warm restarts:** периодически «перезапускается». Иногда лучше.
- **One Cycle:** lr растёт, потом падает, обычно с inverse momentum. Fast.ai стандарт.
- **Warmup:** в начале lr линейно растёт от 0 до целевого, потом обычный schedule. **Обязательно** для трансформеров.

**Почему warmup для трансформеров:** при холодном старте Adam может выдать огромные обновления → нестабильность.

## 7. Что такое dropout и как он работает?

**Что:** на train с вероятностью p зануляет активации нейронов. На eval — оставляет всё, но масштабирует на (1-p).

**Зачем:** регуляризация. Сеть не может полагаться на конкретный нейрон → учится с избыточностью → лучше обобщает.

**Где использовать:**
- MLP скрытые слои: p = 0.2-0.5.
- CNN: меньше эффективен (используют DropPath / Spatial Dropout).
- Трансформеры: на attention (attn_drop) и на FFN (resid_drop), типично 0.1.

**Что не путать:** на inference dropout **выключен**. В PyTorch — model.eval() переводит.

## 8. Что такое weight initialization и почему важна?

**Проблема:** если инициализировать все веса нулями → все нейроны учат одно и то же. Если слишком большими → exploding. Слишком маленькими → vanishing.

**Стандарты:**
- **Xavier/Glorot:** для tanh/sigmoid. std = sqrt(2/(fan_in + fan_out)).
- **He (Kaiming):** для ReLU. std = sqrt(2/fan_in).
- **Trunc normal:** для трансформеров (обрезанный нормал).

**В PyTorch:** дефолтная инициализация nn.Linear — Kaiming uniform, обычно хорошо. Свои слои — инициализируйте явно.

## 9. Объясните, как работает свёртка

**Короткий:** ядро (фильтр) скользит по входу, на каждой позиции считает скалярное произведение между ядром и куском входа.

**Параметры:**
- **kernel_size:** размер ядра (3×3, 5×5, 7×7).
- **stride:** шаг сдвига. 1 — обычно, 2 — снижает разрешение в 2 раза.
- **padding:** добавление нулей по краям. 'same' — выход того же размера, 'valid' — без padding.
- **dilation:** «разреженное» ядро для увеличения receptive field без роста параметров.
- **groups:** разбиение каналов на группы (depthwise convolution).

**Выходной размер:** out = (in + 2·pad - kernel) / stride + 1.

**Зачем CNN лучше MLP для картинок:**
- Параметров на много порядков меньше (sharing weights).
- Translation invariance (паттерн в любом месте — тот же выход).
- Использует локальность.

## 10. Что такое pooling и какие виды?

**Виды:**
- **Max pooling:** берёт максимум по окну. Выделяет «есть ли признак».
- **Average pooling:** среднее. Сглаживает.
- **Global Average Pooling (GAP):** среднее по всей карте признаков. Заменяет финальный FC слой.
- **Adaptive pooling:** к фиксированному выходному размеру вне зависимости от входа.

**Зачем:** снижает разрешение → быстрее → больше receptive field. Добавляет инвариантность к малым сдвигам.

**Современный тренд:** strided convolution вместо pooling в новых архитектурах (ConvNeXt, EfficientNet).

## 11. Что такое residual connections (ResNet)?

**Что:** y = F(x) + x. Выход слоя = его преобразование + сам вход.

**Зачем:**
- Решает vanishing gradients в очень глубоких сетях.
- Учит «дельту», что проще, чем учить функцию с нуля.
- Идентичность всегда доступна как fallback.

**Без residual:** при 50+ слоях качество **падает** даже на train. С residual ResNet-152 обучается без проблем.

**Где ещё используется:** трансформеры (после attention и FFN каждый раз +x), диффузионные U-Net.

## 12. Чем отличается transfer learning от fine-tuning?

**Transfer learning** — общий термин: использование предобученной модели на новой задаче.

**Варианты:**
1. **Feature extraction:** замораживаем backbone, обучаем только новую голову. Быстро, мало данных нужно.
2. **Fine-tuning:** размораживаем (часть) слои и дообучаем с маленьким LR. Лучше качество, больше данных нужно.
3. **Layer-wise unfreezing:** размораживаем по слою, начиная сверху. Стандарт у fast.ai.

**Когда что:**
- < 1K примеров: feature extraction.
- 1K-10K: feature extraction + fine-tune головы и последних блоков.
- 10K+: полный fine-tuning с маленьким LR на backbone.

**Подвох:** для backbone обычно LR в 10-100 раз меньше, чем для головы (discriminative learning rates).

## 13. Что такое data augmentation для картинок?

**Стандартные:**
- Геометрические: flip, rotate, crop, scale, translate.
- Цветовые: brightness, contrast, saturation, hue.
- Шум: Gaussian noise, blur.
- Cutout / Random Erasing: вырезание прямоугольника.
- MixUp: смешивание двух картинок с весами + такое же смешивание лейблов.
- CutMix: вырезаем кусок из одной, вставляем в другую.

**Когда что:**
- Базовый набор: flip + crop + color jitter.
- Малый датасет: добавить MixUp/CutMix.
- Specific tasks: не делать flip для текста, поз и т.п.

**Библиотеки:** torchvision.transforms (просто), albumentations (быстрее, больше).

## 14. Объясните attention на пальцах

**Короткий:** механизм, который для каждого элемента входа решает, на какие другие элементы смотреть и насколько сильно.

**Формула (scaled dot-product):**
```
Attention(Q, K, V) = softmax(Q · K^T / √d_k) · V
```

**На пальцах:**
- **Q (query):** «что я ищу»
- **K (key):** «что у меня есть»
- **V (value):** «что я отдам, если найдут»
- Q·K^T → similarity scores → softmax → weights → взвешенная сумма V.

**Self-attention:** Q, K, V — проекции одного и того же входа. Каждый токен смотрит на все остальные (включая себя).

**Почему √d_k:** при больших d_k скалярные произведения становятся большими по модулю → softmax насыщается → градиенты исчезают. Деление масштабирует.

## 15. Что такое multi-head attention и зачем?

**Что:** параллельные attention-головы с разными Q/K/V проекциями. Их выходы конкатенируются и проектируются обратно.

**Зачем:** каждая голова может специализироваться (синтаксис, семантика, позиции). Аналогично разным фильтрам в CNN.

**Размерности:** если d_model = 512 и h = 8 голов, то d_head = 64 на голову. Параметров суммарно столько же, что и при одной голове d=512.

**Современные варианты:**
- **MQA (multi-query):** одна K и V на все головы. Экономит память.
- **GQA (grouped-query):** группы голов делят K/V. Стандарт в Llama 3, Mistral.

---

## 16. Объясните KV-cache

**Проблема:** при автогенерации каждый новый токен требует пересчёта attention со всеми предыдущими. Без кеша — O(n²) на каждый шаг, суммарно O(n³).

**Решение:** на каждом шаге сохраняем K и V предыдущих токенов. Новый токен → считаем только его Q и attend к закешированным K, V.

**Выигрыш:** O(n²) суммарно вместо O(n³). На длинных последовательностях — порядки разницы.

**Цена:** память растёт линейно с длиной. На длинном контексте KV-cache может занимать больше, чем сама модель.

**Лечение:** MQA/GQA уменьшают KV-cache в 4-8 раз. PagedAttention (vLLM) — управляет памятью как страницами.

## 17. Чем encoder-only, decoder-only и encoder-decoder отличаются?

| Тип | Примеры | Маска attention | Для чего |
|-----|---------|-----------------|----------|
| **Encoder-only** | BERT, RoBERTa | Bidirectional | Классификация, NER, embedding |
| **Decoder-only** | GPT, Llama, Claude | Causal (только назад) | Генерация |
| **Encoder-Decoder** | T5, BART | Encoder bidirectional, decoder causal + cross-attn | Перевод, суммаризация |

**Тренд 2025:** decoder-only выиграли почти все ниши, кроме специализированной классификации. T5 ещё используется, но всё реже.

## 18. Что такое positional encoding?

**Проблема:** трансформер по построению инвариантен к перестановкам входа. «Кот сидит на коврике» = «коврике на сидит кот» для self-attention.

**Решение:** добавить позиционную информацию.

**Варианты:**
- **Sinusoidal (оригинал):** sin/cos разных частот. Не обучаемые.
- **Learned:** обучаемые embedding позиций. Простой, но не экстраполируется.
- **RoPE (Rotary):** поворачиваем Q и K на угол, зависящий от позиции. Хорошо экстраполируется, стандарт в Llama 3.
- **ALiBi:** добавляем линейный bias к attention scores. Дёшево, хорошо для экстраполяции.

## 19. Mixed precision training: что и зачем?

**Что:** обучение в fp16/bf16 вместо fp32. Веса хранятся в fp32 (master copy), forward/backward в fp16/bf16.

**Зачем:**
- В 2 раза меньше памяти.
- В 2-3 раза быстрее на современных GPU (Tensor Cores).
- Качество практически не страдает.

**bf16 vs fp16:**
- fp16 точнее (больше мантисса), но меньший range → underflow/overflow.
- bf16 больший range (как fp32), меньше точность. Стандарт для трансформеров.

**В PyTorch:** torch.autocast() контекстный менеджер + GradScaler для fp16. С bf16 GradScaler не нужен.

## 20. Gradient checkpointing: что и зачем?

**Проблема:** для backprop нужно хранить активации forward. На больших моделях память кончается.

**Решение:** не храним все активации, а пересчитываем их в backward. Экономия памяти ценой ~30% времени.

**В PyTorch:** torch.utils.checkpoint.checkpoint(layer, x).

**Когда использовать:** обучение больших моделей (LLM 7B+), длинные последовательности, на GPU с малой памятью.

## 21. Gradient accumulation: что и зачем?

**Проблема:** хотим большой effective batch (1024), но в GPU влезает только 32.

**Решение:** делаем 32 forward+backward без optimizer.step(), накапливаем градиенты, потом один step. Effective batch = 32 × 32 = 1024.

```python
optimizer.zero_grad()
for i, batch in enumerate(loader):
    loss = model(batch).loss / accum_steps
    loss.backward()
    if (i+1) % accum_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
```

**Подвох:** loss делите на accum_steps, иначе фактический LR будет в N раз больше.

## 22. Что такое DDP и FSDP?

**DDP (Distributed Data Parallel):** каждая GPU держит копию модели, обрабатывает свой batch, градиенты синхронизируются all-reduce.

**Когда:** модель влезает в одну GPU.

**FSDP (Fully Sharded Data Parallel):** параметры/градиенты/optimizer states шардируются между GPU. На каждом шаге нужный параметр собирается all-gather.

**Когда:** модель не влезает в одну GPU. DDP не вариант.

**ZeRO stages (DeepSpeed):**
- Stage 1: shard optimizer states.
- Stage 2: + gradients.
- Stage 3: + parameters (≈ FSDP).

## 23. Чем CNN лучше Transformer для картинок и наоборот?

**CNN сильнее когда:**
- Маленький датасет (< 100K). Inductive bias на локальность помогает.
- Низкие latency requirements.
- Edge / mobile.

**ViT сильнее когда:**
- Большой датасет (миллионы+).
- Multi-modal задачи.
- Можно претренироваться на ImageNet-21K или больше.

**Современный консенсус:** на средних задачах CNN (ConvNeXt) и ViT примерно равны. На больших — ViT лучше масштабируется.

## 24. Что такое semantic segmentation, object detection, instance segmentation?

**Classification:** что на картинке. Один лейбл.

**Object detection:** что и где. Bounding boxes + labels. YOLO, DETR, RT-DETR.

**Semantic segmentation:** каждый пиксель → класс. Не различает экземпляры. DeepLab, Mask2Former.

**Instance segmentation:** semantic + различает экземпляры. Mask R-CNN, Mask2Former.

**Panoptic segmentation:** комбинация semantic + instance. Каждый пиксель — либо «вещь» (countable, например, машины), либо «материал» (uncountable, например, небо).

## 25. Что такое NMS (Non-Maximum Suppression)?

**Контекст:** в object detection одна модель часто выдаёт несколько bounding boxes на один объект.

**Алгоритм:**
1. Сортируем boxes по confidence.
2. Берём самый уверенный, добавляем в результат.
3. Удаляем все boxes с IoU > threshold с этим.
4. Повторяем.

**Параметры:** IoU threshold (обычно 0.5), confidence threshold.

**Альтернативы:** Soft-NMS (понижает score вместо удаления), NMS-free (DETR-семейство — не нужен).

---

## 26. Объясните IoU и mAP

**IoU (Intersection over Union):** для двух boxes — площадь пересечения / площадь объединения. От 0 до 1. Стандартный порог «правильного» детекта — 0.5.

**mAP (mean Average Precision):**
1. Для каждого класса считаем PR-кривую при разных confidence threshold.
2. AP = площадь под PR-кривой.
3. mAP = усреднение AP по всем классам.

**COCO mAP:** усредняем по IoU от 0.5 до 0.95 с шагом 0.05. Жёстче, чем PASCAL VOC mAP@0.5.

## 27. Что такое embedding и как его обучают?

**Что:** dense vector representation сущности (слова, картинки, пользователя).

**Способы получения:**
- **Word2Vec / GloVe:** старые, для слов через skip-gram / CBOW.
- **BERT-like:** embedding из последнего слоя или [CLS]-токена.
- **Sentence-BERT:** дообучение BERT для предложений через triplet loss.
- **CLIP:** совместный train текста и картинок через contrastive loss.
- **OpenAI text-embedding-3, bge, e5:** современные модели embeddings для retrieval.

**Размер:** 384, 768, 1024, 1536, 3072 — типичные.

**Проверка качества:** retrieval recall@k на бенчмарках (MTEB).

## 28. Что такое contrastive learning?

**Идея:** обучаем модель так, чтобы похожие объекты были близко в embedding пространстве, разные — далеко.

**Loss-функции:**
- **Triplet loss:** L = max(0, d(a, p) - d(a, n) + margin). Anchor, positive, negative.
- **InfoNCE:** на батче — каждый pair (anchor, positive) против всех других как negatives. Используется в CLIP, SimCLR.

**Применения:**
- Self-supervised learning (SimCLR, MoCo, DINO).
- Sentence embeddings (Sentence-BERT).
- Multi-modal (CLIP).
- Recommendations (two-tower).

---

## 29. Что такое CLIP и почему он важен?

**Что:** Contrastive Language-Image Pretraining от OpenAI (2021). Два энкодера: текстовый и визуальный, обученные на 400M пар (картинка, подпись) через contrastive loss.

**Почему важен:**
- Zero-shot классификация: даём текстовые лейблы → классифицируем картинки без train.
- Универсальный visual encoder для downstream задач.
- Основа для multi-modal моделей: Stable Diffusion использует CLIP text encoder.
- Открыл эпоху vision-language моделей.

## 30. Что такое diffusion model в одном абзаце?

**Идея:** обучаем модель «удалять шум» из картинки. Forward process: постепенно добавляем гауссовский шум до полного шума. Reverse process: модель учится предсказывать шум, чтобы его убрать.

**На inference:** начинаем со случайного шума, итеративно «убираем шум» через модель → получаем картинку.

**Современные варианты:**
- **DDPM:** оригинал, 1000 шагов.
- **DDIM:** быстрее, 50 шагов.
- **Latent Diffusion (Stable Diffusion):** в латентном пространстве VAE.
- **Flow Matching / Rectified Flow:** упрощённая математика, ещё быстрее.
- **DiT (Sora-like):** трансформер вместо U-Net.

**Управление генерацией:**
- **Classifier-free guidance:** усиление влияния текстового промпта.
- **ControlNet:** структурный контроль (поза, edges).
- **LoRA:** дообучение на стиль/объект.
