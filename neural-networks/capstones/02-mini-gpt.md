# Капстон 2. MiniGPT с собственным датасетом

> Делается **после уроков 7-12**. Цель: обучить **свой** маленький GPT с нуля. После этого проекта вы навсегда перестанете считать LLM магией.

## Что должно быть на выходе

- 🗂️ GitHub-репозиторий, например `my-mini-gpt`.
- 🔤 Свой BPE-токенизатор, обученный на вашем корпусе.
- 🤖 MiniGPT (5-50M параметров), обученный с нуля.
- 💬 Скрипт интерактивной генерации (chat-style).
- 📊 README с loss-кривыми и примерами генерации до/после.

## Выбор корпуса

Делайте на том, что вам **интересно**:

- **Свои дневники / посты / переписка** (5-20 MB текста) — модель «копирует ваш стиль».
- **Корпус классической литературы одного автора** (Толстой, Достоевский, Тургенев) — модель пишет в их стиле.
- **Code-only корпус** одного языка (тысячи Python-файлов из GitHub) — мини-code-completion.
- **Анекдоты или твиты** на одну тему — модель генерирует контент.
- **Тексты по узкой теме** (футбольные репортажи, рецензии на фильмы, рецепты).

Размер корпуса 5-200 MB. Меньше — модель ничего не выучит. Больше — слишком долго обучать на одной GPU.

## Архитектура

Это **расширенный** MiniGPT из урока 09:

```python
class MiniGPT(nn.Module):
    def __init__(self, vocab_size, d_model=384, n_heads=6, n_layers=6,
                 max_len=512, dropout=0.1):
        ...
```

С такими параметрами модель будет ~25M параметров — обучается за 4-8 часов на одной T4 GPU (бесплатный Colab).

## Стек

- **PyTorch** — модель и обучение.
- **tokenizers** (HuggingFace) — обучение BPE.
- **wandb** — логирование.

## Пошаговый план (7-10 дней)

**День 1-2. Данные и токенизатор.**

- Соберите корпус (5-50 MB raw text).
- Почистите: уберите служебные символы, поправьте кодировку, разделите на абзацы.
- Обучите BPE-токенизатор на словаре 8000-16000 (`tokenizers` library, BPE).
- Токенизуйте весь корпус в один большой массив `uint16`, сохраните в `.bin` файл.

**День 3. Модель.**

- Перепишите MiniGPT с pre-LN, learned positional embeddings, GELU.
- Добавьте weight tying (общая матрица для `embedding` и `lm_head`).
- Включите gradient checkpointing — экономит память.

**День 4-7. Обучение.**

- AdamW lr=3e-4 (Karpathy constant), β=(0.9, 0.95), weight_decay=0.1.
- Warmup 500-1000 шагов → cosine до 10% от пика.
- Gradient clipping 1.0.
- Batch `micro_batch × accum` — например, 32×8 = effective 256.
- Логируйте train loss и каждые 500 шагов val loss + сэмпл генерации.
- 50k-200k шагов.

**День 8. Анализ.**

- Постройте train/val loss кривые.
- Сравните loss с теоретическим уровнем «случайной угадайки» (`log(vocab_size)`).
- Сэмплы на 3-х этапах обучения: 10%, 50%, 100%. Видна ли прогрессия?

**День 9. Sampling.**

- Реализуйте temperature, top-k, top-p (nucleus) sampling.
- Сравните выходы при разных параметрах. Какие настройки дают «лучший» текст?

**День 10. Chat-style.**

- Добавьте простой chat-template: `<user>...</user><assistant>...</assistant>`.
- Дообучите 1-2k шагов на 100-200 искусственных диалогах (можно сгенерировать через GPT-4 API).
- Скрипт `chat.py` — интерактивный REPL.

## Расширенные опции (если осталось время)

- **RoPE** вместо learned positional — научитесь экстраполировать на длинный контекст.
- **GQA (Grouped-Query Attention)** — экономия KV-кеша.
- **DPO fine-tune** — соберите 100-200 пар `(chosen, rejected)` и сделайте DPO. Урок 15.
- **Квантизация в int8** при инференсе.
