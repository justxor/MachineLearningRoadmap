# Урок 01. Перцептрон и линейные модели

> Цель урока: понять, что нейрон — это просто скалярное произведение плюс нелинейность, и обучить простейший классификатор без библиотек.

## Теория за 5 минут

**Перцептрон Розенблатта (1957)** — это математическая модель нейрона:

$$
y = \sigma(w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b) = \sigma(\mathbf{w}^\top \mathbf{x} + b)
$$

где `x` — входные признаки, `w` — веса, `b` — смещение (bias), `σ` — нелинейная функция (исторически — шаг Хевисайда, сейчас — сигмоида, ReLU и т.д.).

**Что это значит геометрически.** Один нейрон строит **гиперплоскость** в пространстве признаков и говорит «по одну сторону — класс 0, по другую — класс 1». Если данные линейно разделимы — перцептрон сходится. Если нет (классический пример — XOR) — нужна сеть из нескольких нейронов.

**Правило обновления весов** (исходный алгоритм Розенблатта):

$$
\mathbf{w} \leftarrow \mathbf{w} + \eta (y_{\text{true}} - y_{\text{pred}}) \mathbf{x}
$$

η — скорость обучения (learning rate). Если предсказание совпало с правдой — веса не меняются. Если ошиблись — двигаем их в сторону правильного ответа.

## Минимальная реализация (NumPy, без библиотек ML)

```python
import numpy as np

rng = np.random.default_rng(42)

# Игрушечный датасет: точки двух классов
X = np.array([[2, 1], [3, 2], [3, 3], [1, 4], [1, 1], [2, 0], [0, 1], [0, 2]], dtype=float)
y = np.array([1, 1, 1, 1, 0, 0, 0, 0])

# Инициализация
w = rng.normal(0, 0.1, size=X.shape[1])
b = 0.0
lr = 0.1

def step(z): return (z > 0).astype(float)

for epoch in range(20):
    errors = 0
    for xi, yi in zip(X, y):
        z = xi @ w + b
        y_pred = step(z)
        update = lr * (yi - y_pred)
        w += update * xi
        b += update
        errors += int(y_pred != yi)
    print(f"epoch {epoch}: errors={errors}")
    if errors == 0:
        break

print("веса:", w, "смещение:", b)
```

## Логистическая регрессия — мостик к нейросетям

Перцептрон с шаговой функцией не дифференцируем. Заменим её на **сигмоиду**:

$$
\sigma(z) = \frac{1}{1 + e^{-z}}
$$

Получим логистическую регрессию — простейшую обучаемую градиентным спуском нейросеть из одного нейрона. Функция потерь — **бинарная кросс-энтропия**:

$$
\mathcal{L} = -\frac{1}{N} \sum_i \left[ y_i \log \hat{y}_i + (1 - y_i) \log(1 - \hat{y}_i) \right]
$$

```python
def sigmoid(z): return 1 / (1 + np.exp(-z))

w = rng.normal(0, 0.1, size=X.shape[1])
b = 0.0
lr = 0.5

for epoch in range(500):
    z = X @ w + b
    y_hat = sigmoid(z)
    loss = -np.mean(y * np.log(y_hat + 1e-9) + (1 - y) * np.log(1 - y_hat + 1e-9))
    grad_w = X.T @ (y_hat - y) / len(y)
    grad_b = np.mean(y_hat - y)
    w -= lr * grad_w
    b -= lr * grad_b

print("loss:", loss, "accuracy:", np.mean((y_hat > 0.5) == y))
```

## То же самое в PyTorch

```python
import torch, torch.nn as nn

X_t = torch.tensor(X, dtype=torch.float32)
y_t = torch.tensor(y, dtype=torch.float32).unsqueeze(1)

model = nn.Sequential(nn.Linear(2, 1), nn.Sigmoid())
opt = torch.optim.SGD(model.parameters(), lr=0.5)
loss_fn = nn.BCELoss()

for epoch in range(500):
    y_hat = model(X_t)
    loss = loss_fn(y_hat, y_t)
    opt.zero_grad(); loss.backward(); opt.step()

print("loss:", loss.item())
```

Одни и те же ~5 строк, только PyTorch сам считает градиенты.
