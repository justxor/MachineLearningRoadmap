# 🧠 Нейросети с нуля до продакшна — практический курс

Это второй модульный курс репозитория. После [math-for-ml/](../math-for-ml/README.md) — самое время собрать нейросеть руками и пройти путь от линейного нейрона до собственного трансформера, мультимодальных моделей и распределённого обучения.

## Зачем этот курс

Большинство курсов по нейросетям делают одно из двух:

- Либо учат запускать готовые модели из Hugging Face и называют это «изучить нейросети».
- Либо закапываются в матан и оставляют вас без кода, который реально работает.

Этот курс — про **середину**: достаточно математики, чтобы понимать, что вы делаете, и **очень много кода**, который запускается локально на CPU или бесплатном Colab.

## Кому подходит

- Вы прошли [math-for-ml/](../math-for-ml/README.md) или знаете производные, матрицы и базовую теорию вероятностей.
- Вы умеете писать на Python и работали с NumPy.
- Вы хотите научиться **строить и обучать модели**, а не просто звать `model.fit()`.

## Стек

- **Python 3.10+**, **PyTorch 2.x**, **NumPy**, **Matplotlib**.
- Опционально: **torchvision**, **transformers**, **datasets**, **diffusers**, **peft**, **trl**, **torch_geometric**, **accelerate**.
- Железо: достаточно CPU. Для уроков 9-18 удобнее GPU (бесплатный Colab подойдёт). Для уроков 17-18 — две GPU (или симуляция через `torchrun --nproc_per_node=2`).

## Как проходить

1. **Один урок — одна неделя.** Не пытайтесь пройти всё за выходные.
2. Сначала прочитайте теорию, потом разберите код **построчно**, потом повторите код с нуля, **не подглядывая**.
3. Сделайте **все 8 практических заданий** в конце урока. Без них курс бесполезен.
4. После каждого крупного блока — соответствующий капстон в папке [capstones/](./capstones/README.md).

## Что вы получите на выходе

- Понимание, **что именно происходит** внутри `loss.backward()` и `optimizer.step()`.
- Умение собрать любую современную архитектуру **из примитивов**, а не из готовых блоков: CNN, RNN, Transformer, ViT, GNN, Diffusion.
- Готовый шаблон fine-tuning (LoRA, QLoRA, DPO), который вы сможете повторить на работе.
- Понимание, как модель **уезжает в продакшн** — не «по магии», а через ONNX, квантизацию и REST-обёртку.
- Опыт распределённого обучения (DDP, FSDP, mixed precision).
- 3 портфолио-проекта.

## Принципы

- **80% практики, 20% теории.** Формулы — только те, которые реально пригодятся при отладке.
- **Никакой магии.** В каждом уроке хотя бы один пример «пишем то же самое с нуля без библиотек».
- **Минимум зависимостей.** Чем меньше `pip install`, тем дольше живёт ваш код.
- **Воспроизводимость.** Каждый кусок кода должен запускаться без правок.
