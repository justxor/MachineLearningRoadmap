# Урок 04. Регуляризация: dropout, BatchNorm, weight decay

> Цель урока: научиться диагностировать переобучение и применять три главных инструмента борьбы с ним — weight decay, dropout и нормализацию.

## Переобучение: что это и как его увидеть

**Переобучение (overfitting)** — модель выучила тренировочные данные, включая шум, и плохо работает на новых.

Главный диагностический инструмент — **график train loss vs val loss по эпохам**:

- train ↓, val ↓ → всё хорошо, обучаемся.
- train ↓, val плато → нормальный конец обучения.
- train ↓, val ↑ → **переобучение**. Пора регуляризировать или останавливаться.
- train ≈ val, обе высоко → **недообучение**. Нужна модель посложнее или больше эпох.

**Правило большого пальца:** если разрыв train/val > 5-10% по accuracy — это переобучение.

## Инструмент 1. Weight decay (L2-регуляризация)

Добавляем к функции потерь штраф за большие веса:

$$
\mathcal{L}_{\text{reg}} = \mathcal{L} + \lambda \sum_i w_i^2
$$

Производная этого штрафа = `2λw`. На каждом шаге градиент **уменьшает веса пропорционально их величине**. Отсюда название «weight decay».

В PyTorch — встроено в оптимизатор:

```python
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)
```

**Типичные значения:** `1e-5` до `1e-3`. Для трансформеров часто `0.01-0.1`.

## Инструмент 2. Dropout

На каждом шаге обучения с вероятностью `p` зануляем выход нейрона:

$$
\tilde{h}_i = \begin{cases} 0 & \text{с вероятностью } p \\ h_i / (1-p) & \text{иначе} \end{cases}
$$

Деление на `(1-p)` — чтобы среднее значение активации не менялось.

**Интуиция:** сеть не может полагаться ни на один нейрон по отдельности — каждый может «выпасть». Это заставляет учить избыточные представления.

**Важно:** dropout работает **только в режиме обучения** (`model.train()`). В inference (`model.eval()`) он отключается. Поэтому в PyTorch важно правильно переключать режимы.

```python
import torch.nn as nn
net = nn.Sequential(
    nn.Linear(784, 256), nn.ReLU(), nn.Dropout(0.3),
    nn.Linear(256, 128), nn.ReLU(), nn.Dropout(0.3),
    nn.Linear(128, 10)
)
```

**Типичные значения p:** 0.1-0.5. Перед последним слоём dropout не ставят.

## Инструмент 3. Batch Normalization

После линейного слоя нормируем выход по батчу:

$$
\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \quad y = \gamma \hat{x} + \beta
$$

где `μ_B, σ_B` — среднее и дисперсия по батчу, `γ, β` — обучаемые параметры.

**Что это даёт:**

- Стабилизирует распределение активаций → можно использовать большие learning rate.
- Работает как мягкая регуляризация (шум от случайности батча).
- Ускоряет обучение в 2-5 раз.

```python
nn.Sequential(
    nn.Linear(784, 256), nn.BatchNorm1d(256), nn.ReLU(),
    nn.Linear(256, 128), nn.BatchNorm1d(128), nn.ReLU(),
    nn.Linear(128, 10)
)
```

В трансформерах обычно используют **LayerNorm** (нормирует по фичам внутри одного примера) — мы вернёмся к этому в уроке 09.

## Инструмент 4. Early stopping

Самый простой и часто самый эффективный приём:

```python
best_val = float('inf')
patience, bad = 5, 0
for epoch in range(100):
    train_one_epoch(model, train_loader)
    val_loss = evaluate(model, val_loader)
    if val_loss < best_val:
        best_val = val_loss
        torch.save(model.state_dict(), 'best.pt')
        bad = 0
    else:
        bad += 1
        if bad >= patience:
            print(f"early stop at epoch {epoch}")
            break
```

## Инструмент 5. Аугментация данных

Иногда лучшая регуляризация — не правка модели, а **расширение датасета**. Для картинок: повороты, кропы, цветовые сдвиги (`torchvision.transforms`). Для текста: back-translation, синонимы, dropout на токенах. Для табличных — Mixup, добавление шума к признакам.

## Чек-лист диагностики переобучения

1. Постройте график train/val loss и accuracy.
2. Разрыв > 10%? → начинайте регуляризировать.
3. Сначала **простое**: уменьшите модель или увеличьте данные.
4. Потом **дешёвое**: weight_decay, augmentation, early stopping.
5. Потом **сложное**: dropout, BatchNorm, более сложная аугментация.

## 8 практических заданий

1. **Спровоцируйте overfit.** Возьмите 500 примеров MNIST и сеть 784→1024→1024→10. Обучите 100 эпох без регуляризации. Постройте train/val loss. Должна быть классическая «бабочка».
2. **Weight decay.** Добавьте `weight_decay=1e-3` к AdamW. Постройте те же графики. Что изменилось?
3. **Dropout.** Добавьте `Dropout(0.5)` после каждого скрытого слоя. Сравните с заданием 2.
4. **BatchNorm.** Замените dropout на BatchNorm. Какой подход даёт лучшую val-accuracy?
5. **Все три сразу.** Скомбинируйте weight_decay + BatchNorm + Dropout. Получите best val-accuracy.
6. **Аугментация на CIFAR-10.** Обучите простую CNN на CIFAR-10 с/без `RandomHorizontalFlip + RandomCrop`. Замерьте разницу в accuracy.
7. **Early stopping.** Реализуйте `EarlyStopping` как класс с `patience` и `min_delta`. Используйте на CIFAR-10.
8. **Train vs Eval режим.** Намеренно забудьте `model.eval()` перед validation. Покажите, что test-accuracy падает на 5-10% из-за активного dropout.
