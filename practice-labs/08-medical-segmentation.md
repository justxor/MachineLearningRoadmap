# 🩺 Лаба 08: Semantic segmentation для медицины 🔴

## Цель

Обучить U-Net на медицинских изображениях (опухоль, органы, клетки). Понять специфику: маленькие датасеты, сильный дисбаланс пикселей, cross-validation по пациентам.

## Датасет

- ISIC 2018 (кожные поражения), Kvasir-SEG (эндоскопия), Data Science Bowl 2018 (ядра клеток).
- Маски в PNG, одноклассовая сегментация.

## Минимальный пайплайн

1. Подготовка данных, train/val сплит по пациентам.
2. Аугментации: albumentations (flip, rotate, elastic, brightness).
3. U-Net из segmentation-models-pytorch.
4. Loss = 0.5 * BCE + 0.5 * Dice.
5. Обучение + визуализация предиктов.
6. TTA для финального инференса.

## Метрики

- Dice coefficient (главная).
- IoU (Jaccard).
- Hausdorff distance.
- Обязательно: per-image Dice с боксплотом.

## Расширения

- DeepLabV3+ для сравнения.
- TransUNet (трансформер + U-Net).
- Multi-class segmentation.
- 5-fold CV по пациентам.
- Test-time augmentation + ensembling.

## Критерии приёмки

- [ ] Dice >0.85 на valid.
- [ ] Сплит по пациентам (не по картинкам).
- [ ] Визуализация 10 предиктов (лучших и худших).
- [ ] Боксплот Dice по изображениям.
- [ ] CV результаты mean ± std.

## Анти-паттерны

- ❌ Сплит по картинкам — лик пациента.
- ❌ Оценка по accuracy на пикселях (фон доминирует).
- ❌ Аугментации без синхронизации маски и картинки.
- ❌ Игнор hard cases (их видно в боксплоте).
