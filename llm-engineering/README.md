# 🧠 LLM Engineering — практический курс по разработке приложений на больших языковых моделях

Курс для разработчиков, которые хотят не просто "звать GPT по API", а строить надёжные LLM-системы: RAG, агенты, инструменты, оценка качества, мониторинг, тонкая настройка, локальный инференс. Без хайпа, без курсов "стань промпт-инженером за 3 дня". Только то, что реально работает в проде.

## Кому подходит

- Backend-разработчикам, добавляющим LLM-функции в существующие сервисы.
- ML-инженерам, переходящим с классических моделей на LLM-стек.
- Тимлидам, которым нужно понимать, во что вы ввязываетесь, прежде чем "прикручивать AI".
- Тем, кто прошёл курс по [нейронным сетям](../neural-networks/) и хочет применить трансформеры в продукте.

## Что вы получите на выходе

- Работающий RAG-сервис на ваших документах с метриками качества и стоимости.
- Агентную систему с инструментами, оркестрацией и защитой от бесконечных циклов.
- Набор evals (оффлайн и онлайн), которые ловят регрессии до выкатки.
- Опыт fine-tuning'а (LoRA/QLoRA) и локального инференса (llama.cpp, vLLM).
- Понимание реальной экономики LLM-проектов: latency, стоимость токенов, кэширование.

## Как учиться

Курс построен по принципу "минимум теории — максимум практики". Каждый урок: короткое объяснение → конкретные примеры с кодом → антипаттерны → 6 практических заданий → чек-лист. Идите последовательно, не перепрыгивайте. RAG без понимания эмбеддингов — не RAG, а лотерея.

## Стек, который будем использовать

- Python 3.11+, `uv` или `poetry` для зависимостей.
- API: OpenAI, Anthropic, локальные через Ollama.
- RAG: `pgvector` или Qdrant, `sentence-transformers`, `rank_bm25`.
- Агенты: LangGraph, голый Python (для понимания).
- Evals: `promptfoo`, `ragas`, собственные скрипты.
- Деплой: FastAPI, Docker, Prometheus + Grafana для метрик.

## Что вы НЕ получите

- "10 промптов, которые изменят вашу жизнь". Промпт без evals — гадание на кофейной гуще.
- Готовых решений в стиле "скопируй и продай клиенту". Понимание > копипаста.
- Обещаний, что LLM решит любую задачу. Иногда регулярка — правильный ответ.

## Дальше

После курса вы сможете осознанно проектировать LLM-системы, защищать архитектурные решения цифрами, и понимать, когда задача вообще не для LLM. Это и есть та самая "vibe-coding guru, который понимает, как работает AI внутри".
