## 📋 Контекст

Три дата-саентиста обучили разные модели для предсказания оттока клиентов. Твоя задача — честно сравнить их и выбрать лучшую для продакшна. У каждой модели есть свои предсказания и вероятности.

---

## 📦 Датасет

```python
import numpy as np
np.random.seed(42)
n = 2000

y_true = np.random.binomial(1, 0.2, n)

# Три модели с разными характеристиками
y_proba_A = np.clip(y_true * 0.7 + np.random.normal(0, 0.2, n), 0, 1)  # хороший recall
y_proba_B = np.clip(y_true * 0.6 + np.random.normal(0, 0.15, n), 0, 1) # хороший AUC
y_proba_C = np.clip(y_true * 0.5 + np.random.normal(0, 0.3, n), 0, 1)  # слабая модель

threshold = 0.5
y_pred_A = (y_proba_A >= threshold).astype(int)
y_pred_B = (y_proba_B >= threshold).astype(int)
y_pred_C = (y_proba_C >= threshold).astype(int)
```
