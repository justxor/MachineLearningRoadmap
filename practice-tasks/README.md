## 🎯 Как работать с задачами

1. **Читай условие задачи** внимательно — обрати внимание на ограничения
2. **Попробуй решить самостоятельно** — потрать минимум 30–60 минут
3. **Зафиксируй свой подход** — напиши план перед кодом
4. **Сравни с разбором** — найди отличия и объясни их
5. **Реши похожую задачу** — применяй паттерн на новых данных
