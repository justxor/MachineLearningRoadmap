# 17. Стоимость, токены, контекст

## Из чего складывается стоимость

Каждый вызов модели:

- **input токены** — всё, что отправляется (CLAUDE.md, история, содержимое файлов, ответы MCP, описания инструментов)
- **output токены** — всё, что модель генерирует (текст ответа, вызовы инструментов)
- **cache read/write** — при prompt caching обычно дешевле полных input токенов

Opus дороже sonnet в ~5×. Haiku дешевле sonnet в ~3–5×. Смотри текущие цены на anthropic.com.

## /cost и ccusage

В сессии:

```
/cost
```

Покажет расход текущей сессии.

Примерная общая статистика: установи `ccusage` (community CLI) — покажет расход по дням, моделям, проектам. Читает локальные файлы сессий, ключ не нужен.

## Context window

Практически важно:

- Чем больше контекста — тем дороже вызов
- Чем длиннее история — тем хуже работает внимание модели («lost in the middle»)
- Каждый прочитанный файл остаётся в памяти сессии

## Что съедает токены

1. Огромный CLAUDE.md (>200 строк) — переотправляется каждый вызов
2. Много MCP-серверов с большими tool description (50+ tools — бывает тысячи токенов в одних описаниях)
3. Полное чтение больших файлов (`Read` файла на 5 000 строк)
4. Повторное чтение одного и того же файла в разных местах сессии
5. Ответы MCP, приходящие с фулл-дампами таблиц или веб-страниц

## Стратегии экономии

### /clear после задачи

Самый эффективный приём. Завершил задачу — `/clear`.

### /compact посреди

Если нужно сохранить суть, но история раздулась.

### Мини-CLAUDE.md

50–80 строк — потолок. Дальше выноси в docs/.

### Специализированные сессии

Разные репо — разные сессии. Не запускай всё в одном monorepo-сеансе.

### Subagent для исследования

Поиск/проверка в subagent возвращает в основной контекст только итог, а не все прочитанные файлы.

### Sonnet вместо Opus

Opus резервируй для сложных рефакторингов и архитектурных вопросов. Обычная работа — sonnet.

### MCP включай точечно

Не держи 10 серверов «на всякий случай». Описания только съедают токены и путают модель.

## Приближенная оценка

- 1 строка кода ≈ 7–10 токенов
- 1 000-строчный файл ≈ 8–10 тысяч токенов
- 1 час плотной работы ≈ десятки—сотни тысяч токенов

Смотри `/cost` регулярно — быстро появится интуиция.

## Подписка vs API

- **Claude Pro/Max** — фиксированная цена, лимиты по usage rate. Для индивидуальной работы в большинстве случаев выгоднее.
- **API-ключ** — pay-as-you-go. Нужен для CI, команд, высоких объёмов.

## Практика

1. В течение недели веди `/cost` в конце каждой сессии.
2. Установи `ccusage`, посмотри распределение по проектам.
3. Сократи CLAUDE.md вдвое.
4. Убери неиспользуемые MCP-серверы.
5. Проведи эксперимент: та же задача на sonnet и opus, сравни время и стоимость.
6. Научись делать `/clear` при смене задачи рефлекторно.
7. Для исследования большого кода пробуй отдельный subagent.
8. Для команды оцени месячный бюджет (в январе: ~$50—300 на разработчика при плотном использовании или тариф Max).
