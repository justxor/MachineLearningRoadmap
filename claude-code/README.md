# Курс по Claude Code

Практический курс по использованию **Claude Code** — терминального AI-агента от Anthropic для разработки, рефакторинга, отладки и автоматизации работы с кодом.

Курс рассчитан на инженеров, которые хотят не «писать промпты», а встроить агента в реальный рабочий процесс: чтение больших кодовых баз, написание фич, ревью, миграции, работа с тестами, CI/CD, MCP-серверами и собственными инструментами.

## Что такое Claude Code

Claude Code — CLI-инструмент, который запускает модель Claude в твоём терминале с прямым доступом к файлам, shell-командам, git, тестам, браузеру (через MCP) и любым внешним системам. В отличие от чата, агент сам читает репозиторий, планирует изменения, редактирует файлы, запускает команды и итеративно проверяет результат.

Ключевые отличия от копилотов:
- Работа на уровне репозитория, а не отдельного файла
- Полноценный agent loop: план → действие → наблюдение → коррекция
- Расширяемость через MCP-серверы и кастомные команды
- Headless-режим для CI и автоматизации

## Что ты будешь уметь после курса

- Запускать Claude Code в любом проекте и настраивать CLAUDE.md под команду
- Поручать агенту фичи, баги и рефакторинги без ручного контроля каждого шага
- Писать кастомные slash-команды и подключать MCP-серверы (Postgres, Playwright, Sentry, свои)
- Встраивать агента в CI: автогенерация PR, ревью, починка тестов
- Контролировать стоимость, контекст и риски (permissions, sandbox, git-гигиена)

## Требования

- Терминал (macOS/Linux/WSL), Node.js 18+
- Аккаунт Anthropic с доступом к API или подписка Claude Pro/Max
- Базовое знание git и shell
