# 03. Базовые команды и режимы

## Интерактивный REPL

Запуск:

```bash
claude
```

Внутри вводишь запросы и слэш-команды. Нажатие `Esc` прерывает текущее действие, два раза `Esc` — откат к предыдущему сообщению.

## Headless / one-shot

```bash
claude -p "проверь, что все тесты зелёные, иначе почини"
```

Без REPL — один вызов, один ответ, exit code. Подходит для CI, git hooks, Makefile.

## Ключевые slash-команды

| Команда | Что делает |
|---------|------------|
| `/init` | Генерирует черновик CLAUDE.md по репо |
| `/clear` | Очищает контекст текущей сессии |
| `/compact` | Сжимает историю, сохраняя смысл |
| `/model` | Переключить модель (sonnet/opus/haiku) |
| `/permissions` | Настроить, что разрешено без спроса |
| `/cost` | Сколько потрачено в сессии |
| `/agents` | Управление subagents |
| `/mcp` | Статус MCP-серверов |
| `/review` | Ревью текущих изменений |
| `/help` | Список всех команд |

## Режимы ввода

- **Normal mode** — каждое опасное действие спрашивает подтверждение.
- **Plan mode** (`Shift+Tab` для переключения) — агент только читает и предлагает план, ничего не меняет. Полезно для больших рефакторингов: сначала план, потом выполнение.
- **Auto-accept** (`Shift+Tab` ещё раз) — агент не спрашивает по разрешённым действиям. Рискованно — включай только после настройки permissions.

## Контекстные файлы и «@»

В режиме REPL набери `@` — появится fuzzy-поиск по файлам. Выбранный файл вкладывается в контекст:

```
> @src/auth.ts @tests/auth.test.ts почему тест падает?
```

## Картинки

Скриншоты: просто перетащи в окно или вставь через `Cmd+V`. Работает для UI-багов, дизайна, диаграмм.

## История и возобновление

```bash
claude --continue   # возобновить последнюю сессию в этом каталоге
claude --resume     # выбрать из списка ранее бывших сессий
```

## Когда делать /clear

- Переход на другую задачу в том же репо
- Контекст раздулся и агент начал путаться
- После серии ошибок, когда в контексте мусор

`/compact` мягче — сохраняет суть, но выбрасывает детали.

## Практика

1. Сделай одну задачу в режиме plan, потом выполни план.
2. Запусти `claude -p "список файлов больше 500 строк" --output-format json | jq`.
3. Используй `@` для вкладывания 2–3 файлов в запрос про баг.
4. Переключи модель `/model` внутри сессии и сравни ответы.
5. Откатись через два Esc на 2 сообщения назад и переформулируй запрос.
6. Сделай `/compact` после длинной сессии и посмотри на размер контекста до/после.
7. Проверь `/cost` после дня работы.
8. Включи auto-accept на одну задачу в тестовой ветке.
