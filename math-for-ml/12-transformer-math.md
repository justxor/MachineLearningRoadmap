# Урок 12. Математика трансформеров

> **Зачем это нужно:** трансформеры — основа LLM, vision-моделей, мультимодальных систем. Без понимания, что делает каждая операция внутри, вы будете использовать их как чёрный ящик.

---

## 1. Внимание — самая важная формула в современном ML

$$ \text{Attention}(Q, K, V) = \text{softmax}\left( \frac{Q K^T}{\sqrt{d_k}} \right) V $$

Разберём построчно.

- `Q` — queries (что мы ищем), `K` — keys (по чему ищем), `V` — values (что забираем).
- `Q K^T` — матрица «сходств» между каждой query и каждым key. Это, по сути, скалярные произведения.
- `/ √d_k` — стабилизация: при больших `d_k` числа в `QK^T` слишком велики, softmax становится почти one-hot, градиенты затухают.
- `softmax(...)` по последней оси — превращает сходства в распределение вероятностей.
- `@ V` — взвешенная сумма values по этим вероятностям.

```python
import numpy as np

def softmax(x, axis=-1):
    e = np.exp(x - x.max(axis=axis, keepdims=True))
    return e / e.sum(axis=axis, keepdims=True)

def attention(Q, K, V):
    d_k = Q.shape[-1]
    scores = Q @ K.T / np.sqrt(d_k)
    weights = softmax(scores, axis=-1)
    return weights @ V
```

**Это весь attention.** Запомните формулу. Сможете воспроизвести — поймёте 90% статей по NLP за последние 5 лет.

## 2. Self-attention

В self-attention `Q`, `K`, `V` все приходят от **одной и той же** последовательности через линейные проекции:

```python
Q = X @ W_Q   # (n, d_k)
K = X @ W_K   # (n, d_k)
V = X @ W_V   # (n, d_v)
output = attention(Q, K, V)   # (n, d_v)
```

Каждый токен «смотрит» на все остальные и собирает с них информацию. Это позволяет одному слою захватывать зависимости через всю последовательность (в RNN это невозможно).

---

## 3. Multi-head attention

Один attention видит мир по одной размерности. Multi-head запускает `h` параллельных attention с разными проекциями и склеивает результат:

$$ \text{MultiHead}(Q, K, V) = \text{Concat}(head_1, \dots, head_h) W^O $$

где `head_i = Attention(Q W^Q_i, K W^K_i, V W^V_i)`.

Разные головы фокусируются на разных аспектах: одна — на синтаксисе, другая — на корефернции, третья — на временных связях. Это эмпирически наблюдается в обученных моделях.

---

## 4. Position encoding

Attention сам по себе симметричен — он не знает порядка токенов. Чтобы трансформер понимал последовательность, к эмбеддингам добавляется позиционное кодирование.

**Sinusoidal** (из оригинальной статьи):

$$ PE(pos, 2i) = \sin(pos / 10000^{2i/d}) $$
$$ PE(pos, 2i+1) = \cos(pos / 10000^{2i/d}) $$

**Идея:** на каждой размерности `i` своя частота. Близкие позиции дают похожие коды, далёкие — разные. Можно экстраполировать на длины, не встречавшиеся в обучении.

Современные альтернативы: **RoPE** (вращательное позиционное), **ALiBi** (линейный bias). Они лучше работают на длинных контекстах.

---

## 5. FFN-блок

После attention идёт двухслойный полносвязный блок, применяемый позиционно (к каждому токену независимо):

$$ \text{FFN}(x) = W_2 \cdot \text{GELU}(W_1 x + b_1) + b_2 $$

Обычно `W_1` расширяет в 4 раза, `W_2` возвращает к исходной размерности. Здесь модель учит то, что не сводится к взвешенным суммам.

---

## 6. Residual + LayerNorm

Каждый блок (attention или FFN) обёрнут в:

$$ y = \text{LayerNorm}(x + \text{Sublayer}(x)) $$

(в современных моделях: pre-LN — норма до, после — резидуал.)

Residual решает vanishing gradient на глубоких сетях. LayerNorm стабилизирует распределение активаций.

---

## 7. Полная архитектура декодера (как в GPT)

```
input → embeddings + pos_enc
↓
[ block × N ] где block = masked self-attn + FFN, оба с residual + LN
↓
LM head (линейный + softmax) → logits токенов
```

**Masked self-attention** — токен `i` видит только токены `≤ i` (применяем маску `-∞` на верхний треугольник до softmax). Это делает модель авторегрессивной.
