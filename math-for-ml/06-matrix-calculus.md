# Урок 06. Матричное дифференцирование

> **Зачем это нужно:** в ML формулы пишутся в матричной форме, и градиенты тоже. Без матричных производных вы не выведете ничего сложнее линейной регрессии.

---

## 1. Соглашения и обозначения

Есть две конвенции записи градиентов: numerator layout и denominator layout. В ML стандартно используется **denominator layout** — градиент имеет ту же форму, что и переменная, по которой дифференцируем.

- Скаляр по вектору: `∂y/∂x` — вектор той же размерности, что `x`.
- Скаляр по матрице: `∂y/∂W` — матрица той же формы, что `W`.
- Вектор по вектору: `∂y/∂x` — матрица (якобиан).

---

## 2. Базовые формулы (запомнить наизусть)

| Выражение | Производная по x |
|-----------|------------------|
| `y = a^T x` | `a` |
| `y = x^T A x` | `(A + A^T) x` |
| `y = x^T A x`, A симм. | `2 A x` |
| `y = ||x||²` | `2 x` |
| `y = ||x||` | `x / ||x||` |
| `y = Ax` | `A` (якобиан) |

По матрице `W`:

| Выражение | Производная по W |
|-----------|------------------|
| `y = a^T W b` | `a b^T` |
| `y = ||Wx - y||²` | `2(Wx - y) x^T` |
| `y = tr(W^T A)` | `A` |
| `y = tr(W A W^T)` | `W(A + A^T)` |

Это **рабочий минимум**. Распечатайте и держите рядом.

## 3. Якобиан

Для функции `f: R^n → R^m` якобиан — это матрица m × n:

$$ J_{ij} = \frac{\partial f_i}{\partial x_j} $$

Пример: `f(x, y) = (x² + y, xy)`.

$$ J = \begin{pmatrix} 2x & 1 \\ y & x \end{pmatrix} $$

```python
import numpy as np

def f(v):
    x, y = v
    return np.array([x**2 + y, x*y])

def jacobian_numeric(f, v, h=1e-5):
    n = len(v)
    f0 = f(v)
    m = len(f0)
    J = np.zeros((m, n))
    for j in range(n):
        vp, vm = v.copy(), v.copy()
        vp[j] += h
        vm[j] -= h
        J[:, j] = (f(vp) - f(vm)) / (2*h)
    return J

print(jacobian_numeric(f, np.array([1.0, 2.0])))
# Ожидаем [[2, 1], [2, 1]]
```

## 4. Гессиан

Матрица вторых производных `H_{ij} = ∂²f / ∂x_i ∂x_j`. Используется в методах второго порядка (Ньютон, L-BFGS) и в анализе кривизны (седло? минимум?).

Свойства:
- Симметричный (теорема Шварца).
- Положительно определён в локальном минимуме.
- Знакопеременен в седловой точке.

## 5. Градиент линейной регрессии руками

Дано: `L(w) = ||Xw - y||²`. Найдём `∂L/∂w`.

Раскроем: `L = (Xw - y)^T (Xw - y) = w^T X^T X w - 2 y^T X w + y^T y`.

По правилам:
- `∂(w^T X^T X w)/∂w = 2 X^T X w` (поскольку `X^T X` симметрична).
- `∂(-2 y^T X w)/∂w = -2 X^T y`.
- `∂(y^T y)/∂w = 0`.

Итого: `∂L/∂w = 2 X^T X w - 2 X^T y = 2 X^T (Xw - y)`.

Приравниваем к нулю и получаем нормальные уравнения: `X^T X w = X^T y`.

**Это вы только что вывели линейную регрессию из первых принципов.**

---

## 6. Градиент logistic regression

`L = -Σ [y_i log σ(x_i^T w) + (1-y_i) log(1 - σ(x_i^T w))]` (бинарная cross-entropy).

После аккуратной выкладки:

$$ \nabla_w L = X^T (\sigma(Xw) - y) $$

**Запомните этот результат:** для линейной модели с любой каноничной функцией потерь (MSE / cross-entropy / softmax-CE) градиент имеет вид `X^T (предсказание − правда)`. Это глубокая закономерность из теории экспоненциальных семейств.
