# Урок 04. Производные и градиенты

> **Зачем это нужно:** обучение любой модели — это движение по антиградиенту функции потерь. Если не понимаете производную, не понимаете обучение.

---

## 1. Производная как скорость изменения

Производная функции `f(x)` в точке `x₀` — это насколько быстро меняется `f` при изменении `x` в окрестности `x₀`.

$$ f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h} $$

Геометрически — это тангенс угла наклона касательной к графику.

```python
import numpy as np

def derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)   # центральная разность точнее

f = lambda x: x**3 + 2*x
print(derivative(f, 1.0))   # ≈ 5.0 (аналитически: 3x² + 2 = 5)
```

## 2. Таблица производных, которую надо знать

| Функция | Производная |
|---------|-------------|
| `x^n` | `n·x^(n-1)` |
| `e^x` | `e^x` |
| `ln(x)` | `1/x` |
| `sin(x)` | `cos(x)` |
| `cos(x)` | `-sin(x)` |
| `σ(x) = 1/(1+e^-x)` | `σ(x)(1-σ(x))` |
| `tanh(x)` | `1 - tanh²(x)` |
| `ReLU(x)` | `1` если `x > 0`, иначе `0` |

Сигмоиду и ReLU выучите наизусть — будете дифференцировать постоянно.

## 3. Частные производные

Для функции нескольких переменных `f(x, y)` частная производная по `x` — это производная, считающая `y` константой.

$$ \frac{\partial f}{\partial x}, \quad \frac{\partial f}{\partial y} $$

Пример: `f(x, y) = x²y + 3y`.
- `∂f/∂x = 2xy`
- `∂f/∂y = x² + 3`

```python
def f(x, y):
    return x**2 * y + 3*y

def partial_x(x, y, h=1e-5):
    return (f(x+h, y) - f(x-h, y)) / (2*h)

print(partial_x(2.0, 5.0))   # ≈ 20.0 (2·2·5)
```

## 4. Градиент

Градиент — это вектор всех частных производных:

$$ \nabla f = \left( \frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \dots, \frac{\partial f}{\partial x_n} \right) $$

**Ключевое свойство:** градиент направлен в сторону **наибольшего возрастания** функции. Антиградиент — в сторону наискорейшего убывания. Поэтому в оптимизации мы движемся `x ← x - lr · ∇f(x)`.

```python
def numerical_gradient(f, x, h=1e-5):
    grad = np.zeros_like(x)
    for i in range(len(x)):
        x_p, x_m = x.copy(), x.copy()
        x_p[i] += h
        x_m[i] -= h
        grad[i] = (f(x_p) - f(x_m)) / (2*h)
    return grad

f = lambda v: v[0]**2 + 3*v[1]**2
x = np.array([1.0, 2.0])
print(numerical_gradient(f, x))   # ≈ [2.0, 12.0]
```

## 5. Градиентный спуск своими руками

```python
def gradient_descent(f, grad_f, x0, lr=0.1, steps=100):
    x = x0.copy()
    history = [x.copy()]
    for _ in range(steps):
        x -= lr * grad_f(x)
        history.append(x.copy())
    return x, history

# Минимизируем f(x, y) = x² + 3y²
f = lambda v: v[0]**2 + 3*v[1]**2
grad = lambda v: np.array([2*v[0], 6*v[1]])

x_min, hist = gradient_descent(f, grad, np.array([3.0, 4.0]), lr=0.1, steps=50)
print(x_min)   # ≈ [0, 0]
```

## 6. Когда GD ломается

- **Слишком большой learning rate** — траектория «прыгает» и расходится.
- **Слишком маленький lr** — спуск идёт целую вечность.
- **Овраг** (вытянутая долина) — алгоритм зигзагит, не двигаясь к минимуму. Лечение: момент, Adam.
- **Седловые точки** — градиент = 0, но это не минимум. В высоких размерностях их больше, чем локальных минимумов.
