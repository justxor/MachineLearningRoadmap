# 07. EDA: разведочный анализ по чек-листу

EDA — это не рисовать hist по каждой колонке. Это сформулировать и проверить гипотезы о данных до того, как писать модели.

## Чек-лист EDA

1. **Структура.** Сколько строк/колонок, типы, память.
2. **Пропуски.** Где и почему.
3. **Распределения.** Не только mean: medians, квантили, skewness.
4. **Категории.** Частоты, редкие значения.
5. **Целевая переменная.** Баланс классов / распределение.
6. **Связи.** Корреляции, двумерные плоты, mutual information.
7. **Время.** Сезонность, тренд, выбросы во времени.
8. **Группы.** Срезы по ключевым сегментам.
9. **Утечка.** Есть ли фичи, которые в проде недоступны в момент предикта.
10. **Гипотезы.** Что вы увидели и что из этого следует.

## Инструменты

- pandas describe / info.
- ydata-profiling, sweetviz — быстрый скан.
- matplotlib / seaborn для вдумчивых графиков.
- plotly для интерактива.

## Антипаттерны

- Строить 50 графиков без выводов.
- Смотреть только на средние.
- Игнорировать сезонность.
- Не проверять утечки фичей.

## Практика

1. На любом реальном датасете пройдите весь чек-лист.
2. Сформулируйте 5 гипотез и проверьте их.
3. Напишите отчёт на 1–2 страницы: факты → выводы → вопросы.
4. Найдите потенциальные утечки фичей.
5. Постройте сегментацию целевой переменной по 3 срезам.
6. Оформите EDA-notebook в порядке: вопрос → график → ответ.

## Чек-лист

- [ ] Делаю выводы, не только графики.
- [ ] Проверяю утечки.
- [ ] Пишу отчёт для человека, а не для себя.
