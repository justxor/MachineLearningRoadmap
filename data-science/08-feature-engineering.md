# 08. Feature engineering

Фичи решают больше, чем выбор алгоритма. На табличных данных хорошие фичи + слабый бустинг выигрывают у слабых фичей + sota.

## Семейства фичей

- Числовые: лог-трансформы, биннинг, выбросов-робастные преобразования.
- Категориальные: one-hot, target encoding (с осторожностью), CatBoost native.
- Даты: день недели, месяц, выходные, праздники, синус/косинус-кодировка.
- Агрегации: по группам (user, item, store), скользящие окна.
- Лаговые фичи в временных рядах.
- Текст: TF-IDF, длина, количество цифр/URL, эмбеддинги.
- Гео: расстояния, geohash, плотность POI.

## Target encoding без утечки

- Считайте на K-fold out-of-fold.
- Сглаживайте редкие категории (smoothing).
- Сохраните фиттирование только на трейне.

## Пайплайн

- sklearn Pipeline / ColumnTransformer.
- Обучаемые преобразования — fit только на train.
- Сериализуйте пайплайн, не отдельные преобразования.

## Антипаттерны

- target encoding на всём датасете.
- StandardScaler на train+val вместе.
- Один огромный OneHot на редкие категории (10 000 колонок).
- Лаговые фичи из будущего во временном ряде.

## Практика

1. Сделайте 50+ фичей из исходных 5–10 колонок.
2. Оцените фичи через permutation importance.
3. Напишите ColumnTransformer с выбором по dtype.
4. Проверьте target encoding без утечки на трейн/валид.
5. Сделайте lag-фичи для прогноза временного ряда.
6. Документируйте фичи в features.md.
