# 09. Визуализация: matplotlib, seaborn, plotly

Визуализация — это язык, на котором вы говорите с бизнесом и с собой. Чем яснее график, тем быстрее решение.

## Принципы

- Один график — одна мысль.
- Ось из нуля или явное обоснование отреза.
- Подписи, единицы, источник.
- Цвет несёт информацию, а не декорацию.
- Совместимые с дальтонизмом палитры.

## Когда что использовать

- Распределения: histogram, kdeplot, ECDF (часто недооценён).
- Сравнение групп: boxplot, violinplot, stripplot.
- Связь двух переменных: scatter, hexbin.
- Временные ряды: line, area, ribbon для доверительных интервалов.
- Категории: bar (горизонталь при длинных названиях).
- Матрицы: heatmap.

## Антипаттерны

- 3D pie chart.
- Круговые диаграммы для >5 категорий.
- Оси без подписей.
- Обрезанные оси без указания.
- Слишком много цветов просто потому что можно.

## Практика

1. Возьмите произвольный публичный график и перерисуйте его лучше.
2. Сделайте ECDF вместо гистограммы для своих данных. Почувствуйте разницу.
3. Постройте small multiples (5×2) по сегментам.
4. Настройте plotly-график с фильтрами.
5. Оформите себе style.mplstyle и используйте во всех проектах.
6. Сделайте dashboard на streamlit из 3–4 графиков.

## Чек-лист

- [ ] График понятен без подписи внизу.
- [ ] Из графика можно вывести действие.
- [ ] Нет «декоративного» цвета.
