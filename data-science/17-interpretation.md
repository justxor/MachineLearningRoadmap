# 17. Интерпретация моделей: SHAP, permutation importance

Модель без объяснения — чёрный ящик, который сложно «продать» бизнесу и вредно в проде.

## Зачем

- Объяснить решение стейкхолдеру.
- Отлавливать утечки и «слишком хорошую» модель.
- Находить баги в фичах.
- Проходить regulatory-требования (финтех, медицина).

## Методы

- **Коэффициенты** линейных моделей (при стандартизации фичей).
- **Permutation importance.** Работает для любой модели.
- **SHAP.** Game-theoretic подход, локальные и глобальные объяснения.
- **Partial dependence / ICE plots.** Как меняется предсказание при изменении одной фичи.
- **LIME.** Локальные линейные аппроксимации.
- **Surrogate models.** Обучить дерево предсказывать предсказания чёрного ящика.

## SHAP на практике

```python
import shap
explainer = shap.TreeExplainer(model)
shap_values = explainer.shap_values(X_val)
shap.summary_plot(shap_values, X_val)
```

## Антипаттерны

- Смотреть только на feature_importances_.
- Объяснять модель «domain logic», подстраивая под интуицию.
- Один график SHAP и «всё понятно».

## Практика

1. Постройте SHAP-summary и подбор топ-10 фичей.
2. Объясните одно конкретное предсказание через force plot.
3. Сравните важность фичей 3 разными методами.
4. Нарисуйте partial dependence для 3 ключевых фичей.
5. Используйте SHAP, чтобы найти утечку фичи.
6. Подготовьте 5 слайдов, объясняющих модель нетехнической аудитории.
