# 21. Связь модели с метриками бизнеса

Даже идеальная модель бесполезна, если не двигает бизнес-метрики. Связь между ML и бизнесом — ответственность Data Scientist’а, не продакт-менеджера.

## Иерархия метрик

1. **North Star бизнеса.** Revenue, retention, GMV.
2. **Продуктовые KPI.** Activation rate, conversion, AOV.
3. **Метрики фичи.** CTR, completion rate.
4. **ML-метрики.** AUC, MAE, NDCG.

Каждый уровень должен быть связан с верхним. Если «AUC вырос, выручка нет» — это вопрос.

## Как связывать

- Оценить влияние прироста ML-метрики на бизнес через simulations / эксперименты.
- Прикинуть expected impact до работы.
- Считать expected value, не только accuracy.
- Cost-sensitive взвешивание ошибок.

## Пример скоринга кредитов

- FP (дать плохому) → убыток тела кредита.
- FN (не дать хорошему) → недополученная прибыль.
- Оптимизируем expected profit, не ROC-AUC.

## Антипаттерны

- Оптимизация метрики, оторванной от бизнеса.
- «Сосредоточимся на точности» при имбалансе 1:1000.
- Игнорировать second-order effects (каннибализация, retention).

## Практика

1. Нарисуйте иерархию метрик для выбранного продукта.
2. Сформулируйте expected profit для любой классификации.
3. Подберите порог по cost matrix.
4. Оцените expected impact роста AUC на 0.01.
5. Найдите 1 метрику, которую можно взломать (Goodhart’s law).
6. Опишите guardrails для этой метрики.
