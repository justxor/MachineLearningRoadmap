# Капстон 3. Дашборд + модель в проде

Цель: пройти путь от сырых данных до «живого» инструмента, которым пользуются стейкхолдеры.

## Сценарий

Сделать систему: прогноз спроса / скоринг / рекомендации + дашборд для конечных пользователей.

## Шаги

1. **ML-канвас и план.**
2. **Пайплайн данных.** Airflow / Prefect.
3. **Обучение модели.** MLflow tracking.
4. **API.** FastAPI с валидацией входа.
5. **Дашборд.** Streamlit / Dash / metabase — интерфейс для конечных пользователей.
6. **Мониторинг.** Evidently или свой metrics-сбор.
7. **Документация.** README, ADR, runbook.
8. **Demo.** 2–3 минутный видео-ролик с прохождением сценария.

## Критерии приёмки

- Система работает в docker-compose.
- Дашборд интерактивен, фильтры работают.
- Модель версионируется в MLflow.
- Есть monitoring и алерт на drift.
- Репозиторий оформлен, воспроизводим.
- Demo публично доступен (при возможности).

## Дедлайн

3–4 недели. Главный проект в портфолио.
