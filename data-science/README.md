# Data Science — прикладной курс

Курс для тех, кто хочет уметь решать задачи бизнеса данными: от постановки гипотезы до выкатки модели и мониторинга. Без воды, с конкретными артефактами в каждом уроке.

## Для кого

- Аналитик, который хочет расти в ML/DS
- Разработчик, переходящий в DS
- ML-инженер, которому не хватает продуктовой части (метрики, A/B, бизнес)

## Что вы получите на выходе

- 4 портфолио-проекта на GitHub: EDA, продакшн-ML, A/B-тест, дашборд
- Шаблоны: ТЗ на модель, проектная папка, отчёт по A/B, ML-канвас
- Навык доводить задачу от «есть данные» до «решение в проде с метриками»

## Как проходить

1. Делайте задания руками, не копируйте код.
2. Каждый урок → коммит в свой репозиторий с README и выводами.
3. После каждого блока — мини-ретроспектива: что узнал, где буксую.
4. Капстоны выкладывайте отдельными репозиториями — они станут портфолио.

## Предварительные требования

- Базовый Python (функции, классы, list/dict)
- Школьная математика, желательно — [math-for-ml](../math-for-ml/README.md)
- Git на уровне clone/commit/push
